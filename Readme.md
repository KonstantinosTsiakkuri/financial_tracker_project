# Financial Analytics Tracker

## Описание проекта
Скрипт для автоматического расчета ожидаемой прибыли по накопительному счету и конвертации текущего баланса в иностранные валюты (USD, EUR). 

Проект запрашивает актуальные курсы валют через API Центробанка РФ, производит математические расчеты на основе заданных параметров счета (баланс и процентная ставка) и формирует итоговый отчет в формате JSON. Проект построен по модульной архитектуре (`src-layout`) с акцентом на изоляцию бизнес-логики от внешних запросов.
